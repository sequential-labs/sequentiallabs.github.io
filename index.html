Current projects
Solicit
data service

The canonical source of upcoming comic release data. Ingests weekly listings, maps them to ComicVine IDs, and serves them to downstream consumers. Drop-in compatible with existing tools like Mylar3.

Go PostgreSQL REST API in development
Pullsheet
application

Automated comic acquisition and organization for self-hosters. The modern successor to Mylar3, built for the *arr ecosystem. Pairs with readers like Komga, Kavita, and Panels.

self-hosted *arr-style open source coming soon
